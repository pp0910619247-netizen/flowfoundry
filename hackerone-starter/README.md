# HackerOne Starter Kit — เส้นทางทำเงินจาก Bug Bounty อย่างถูกกฎหมาย

## ความจริงก่อนเริ่ม (ไม่หลอก)

- เงินจริงเกิดที่ **HackerOne bounty** — จ่ายเข้าบัญชีของ**คุณ** (PayPal/bank ที่ผูกกับตัวตนคุณ)
- ผมเตรียมทุกอย่างให้: ห้องฝึก, แผน, เทมเพลตรายงาน, เป้าหมายฝึก — แต่**บัญชี HackerOne และการล่าจริงต้องใช้ตัวตนคุณ**
- รายได้มือใหม่: VDP (ไม่จ่าย แต่ให้ reputation) → public program จ่าย $50–500/รายงาน → private (จาก CTF invitation) จ่ายมากขึ้น ไม่มีใครปิดดีลเงินก้อนใน 48 ชม.โดยไม่มีทักษะ — เส้นทางนี้คือลงทุน 30 วัน

## เส้นทาง 30 วัน

### สัปดาห์ 1: พื้นฐาน (1–2 ชม./วัน)
1. สมัคร HackerOne: https://hackerone.com (บัญชีของคุณเอง)
2. เปิด Hacker101: https://www.hacker101.com — ดูวิดีโอแนะนำ (ฟรี)
3. สมัคร Hacker101 CTF: https://ctf.hacker101.com — **ฟรี เปิดให้ทุกคน**
4. รันห้องฝึกในเครื่องนี้: `powershell -File lab-setup.ps1` → http://localhost:3000

### สัปดาห์ 1–2: เก็บ flag CTF (นี่คือบัตรผ่านตลาด)
- เลือกชาเลนจ์เรียงจากง่าย (เขียนว่า easy) ไปยาก
- เก็บ flag ให้ได้มากขึ้น = ระดับขึ้น → **HackerOne ส่งคำเชิญเข้า private bounty program ให้เอง** ตามเกณฑ์ในโปรไฟล์ CTF
- ชาเลนจ์ CTF ครอบคลุม: XSS, SQL injection, IDOR, crypto เบื้องต้น, HTTP tricks — เรียนจากการทำจริง

### สัปดาห์ 3–4: ล่าจริงบนเป้าหมายถูกกฎหมาย
- เริ่มจาก **VDP** (รายงานได้ ยังไม่จ่ายเงิน แต่สร้าง reputation): โปรแกรมของรัฐ/บริษัทใหญ่ที่ประกาศรับรายงาน
- แล้วขยับสู่ **public bounty programs** บน HackerOne ที่ scope กว้าง
- ใช้เทมเพลต `report-template.md` — รายงานที่ชัด = ได้เงิน, รายงานกำกวม = closed

## กฎเหล็ก (ผิด = โดนแบน ไม่มีเงิน)

1. **อ่าน scope ของโปรแกรมก่อนยิงทุกครั้ง** — นอก scope = ผิดกฎหมายจริง
2. ห้าม DoS/brute force/สแกนรุนแรงเกินจำเป็น
3. ห้ามลบ/แก้ข้อมูลจริง ทดสอบเท่าที่จำเป็นพิสูจน์ผลกระทบ
4. รายงานซ้ำ (duplicate) ไม่ได้เงิน — ค้นก่อนว่ามีคนรายงานแล้วหรือยัง
5. อย่าเผยแพร่ก่อนโปรแกรมปิดรายงาน

## เครื่องมือขั้นต่ำ (ฟรีทั้งหมด)

| เครื่องมือ | ใช้ทำอะไร |
|---|---|
| Browser DevTools (F12) | ดู request/response, แก้พารามิเตอร์, IDOR |
| Burp Suite Community | intercept/replay คำขอเว็บ (ดาวน์โหลด: portswigger.net) |
| curl (มีใน Windows แล้ว) | ยิง request ซ้ำอัตโนมัติเบา ๆ |
| Juice Shop ในเครื่องนี้ | สนามฝึกตายใน 30+ ช่องโหว่จริง |

## วิธีเล่น Juice Shop ให้เป็นบทเรียน

1. เข้า http://localhost:3000 → ลองทำตามสิ่งที่เรียนใน Hacker101
2. ชาเลนจ์ซ่อนอยู่ทั่วไซต์: ลองค้นหาสินค้าด้วย `'`, ดู API `/rest/products/search`, ทดลองสมัครสมาชิกด้วยอีเมลที่มี SQL, ดู console ของเว็บ
3. เคล็ดลับ: เปิด DevTools → localStorage มีตารางความคืบหน้า และตอบ flag จะโชว์เมื่อทำถูก
4. เป้า: เก็บ 10+ flag ใน Juice Shop แล้วค่อยไป CTF จริง — จะไม่งง

## กำหนดวัดผล

- สัปดาห์ 1: สมัครครบ + Juice Shop รันได้ + เก็บ flag CTF แรก
- สัปดาห์ 2: flag 5 ตัวขึ้นไปใน CTF
- สัปดาห์ 4: ส่งรายงานแรกเข้า VDP/public program อย่างน้อย 1 ฉบับ
