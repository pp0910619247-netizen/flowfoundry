# LUMA — สมองจำลองที่จำได้ สงสัย และเรียนรู้

สถาปัตยกรรมความคิดจำลอง (brain-inspired cognitive architecture) ขนาดจิ๋ว ทำงาน 100% offline ในเบราว์เซอร์ รันบนมือถือได้ทันที

## สิ่งที่มันทำได้จริง (ไม่ใช่มายางลม)

- **จำได้ข้ามวัน** — ความจำทั้งหมดเก็บใน localStorage ปิดเว็บแล้วเปิดใหม่ มันยังจำคุณได้ รู้ด้วยว่ารู้จักกันมากี่วัน
- **ความจำระยะสั้นที่จางหาย** — Working memory จำได้ ~9 ช่อง พอพูดเรื่องใหม่ เรื่องเก่าจางลง (decay) เหมือนคนจริง
- **เรียนรู้ความเชื่อมโยง (Hebbian)** — มโนทัศน์ที่ปรากฏพร้อมกันบ่อย ๆ เส้นเชื่อมยิ่งแข็งแน่น "เห็นไฟไปด้วยกัน = จีบกัน" แบบเซลล์ประสาท
- **สงสัยด้วยตัวเอง** — มันมองหามโนทัศน์ที่ยัง "เชื่อมไปไม่ได้" แล้วตั้งคำถามถามคุณเอง (intrinsic curiosity)
- **นอนแล้วจัดระเบียบความจำ** — ทุก ๆ 8 ครั้งที่คุย หรือกดปุ่ม "นอน" มันจะลบความเชื่อมจาง ๆ ทิ้ง สรุปเหตุการณ์เก่าเป็นความรู้ (sleep consolidation แบบ Ebbinghaus)
- **เห็นสมองคิดสด ๆ** — กราฟ force-directed ที่โหนดกระพริบตาม activation ของ working memory ลากโหนดด้วยนิ้วได้
- **ลืมได้** — ปุ่มลบความจำ หรือปล่อยให้การนอนลืมของจางไปเอง

## สิ่งที่มันไม่ใช่ (พูดตรง ๆ)

- **ไม่ใช่ LLM ไม่ใช่ AGI** — ไม่มีโมเดลภาษาขนาดใหญ่ การตอบมาจากการค้นคืนความจำ + เทมเพลต
- การตัดคำไทยเป็น heuristic (พจนานุกรม longest-match + trigram fallback) ไม่ใช่ตัวตัดคำระดับ production
- ไม่รับรองผลตอบแทนใด ๆ เป็นแค่ของเล่นวิทยาศาสตร์ที่ทำงานจริง

## โครงสร้างสมอง

```
input → tokenize → WorkingMemory (RAM สั้น + decay)
        ├→ SemanticGraph (ความจำยาว, Hebbian edges, prune ตอนนอน)
        ├→ EpisodicMemory (ไดอารี + ค้นคืนด้วย trigram Dice similarity)
        ├→ Curiosity (เลือกสิ่งที่ degree=0 มาถาม)
        └→ SleepCycle (prune + compress เหตุการณ์เก่า → สรุปเป็น §วันที่)
output ← ResponseEngine (คำสั่ง → ความจำคล้าย → ความสงสัย → ความเชื่อมใหม่)
```

## วิธีรัน

1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (มือถือหรือคอมก็ได้) หรือ
2. เสิร์ฟผ่าน local server:
   - `python -m http.server 8123` (จากโฟลเดอร์แม่) แล้วเปิด `http://localhost:8123/luma-brain/`
   - หรือ `npx serve luma-brain`

## ทดสอบว่าสมองทำงานจริง

```
node luma-brain/smoke-test.js
```

จะรันสมองใน Node (โหมด RAM): สอนเรื่องกาแฟ 2 ประโยค → ทดสอบการค้นคืนความจำ → ให้นอนจัดระเบียบ → รายงานผล PASS/FAIL

## ตั้งค่า

แก้ `LUMA_CONFIG` ต้นไฟล์ `brain.js`: ความจุความจำสั้น, อัตราจาง, ความแน่นของเส้นเชื่อม, ความถี่การนอน

## Roadmap (ถ้าอยากต่อ)

- PWA + manifest → ติดตั้งเป็นแอปบนมือถือ ทำงาน offline เต็มรูปแบบ
- ต่อ Ollama/local LLM เป็น "เปลือกภาษา" โดยให้ LUMA เป็น "ความจำ+แรงจูงใจ"
- export/import สมองเป็นไฟล์ JSON เพื่อแชร์หรือสำรอง
- เสียงพูดเข้า-ออก (Web Speech API)
